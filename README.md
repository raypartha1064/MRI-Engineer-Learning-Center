# MRI Engineer Learning Center

Static web edition prepared for GitHub Pages.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload the CONTENTS of this folder to the repository root.
   - `index.html` must be in the repository root.
   - Keep the `resources`, `pages`, and `assets` folders intact.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then save.
6. GitHub will provide the public website address after deployment.

This package is a static site: HTML, CSS, JavaScript, and local PDF files only.
No server-side software or database is required.
