MRI ENGINEER LEARNING CENTER — OFFLINE VERSION 1.0
Author: Ray Partha

HOW TO USE
1. Unzip the folder.
2. Open index.html in Chrome, Edge, Safari or Firefox.
3. No internet connection is required.
4. Use the Search box to find a topic.
5. Topic pages open the included local PDF references.

PORTABILITY
The site uses only HTML, CSS, JavaScript and PDF files.
It does not depend on macOS, Windows, iPadOS, Android, Linux, TinyServer, WordPress, or a cloud service.
You can copy the entire folder to an SSD/HDD, USB drive, Windows PC, Mac, tablet storage, or a web server later.

IMPORTANT
Keep the folder structure intact. The "resources" folder contains the PDFs used by the website.


LITE EDITION
This version omits the two large complete-book PDFs to make the package easier to download on tablets.
All individual topic PDFs and the full offline website navigation/search remain included.
The original full package is still available separately for laptop/desktop use.


IPAD / TABLET OPTIMIZED EDITION
The individual topic PDFs in this package are compressed for a much smaller download.
They retain the same page layouts and are intended for on-screen reference.
For maximum-resolution originals and the two complete books, use the Full version on a laptop/desktop.
