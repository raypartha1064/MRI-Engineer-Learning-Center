Grainy / Low SNR

Noisy or grainy image; weak signal relative to background noise.

First: Applications / Tech checks

  • Confirm correct coil and coil elements
  • Check patient/coil positioning and coverage
  • Compare FOV, matrix, slice thickness, NEX and acceleration with a known-good protocol

Then: Engineer checks

  • Review coil connection/elements
  • Review prescan/RG behavior
  • Consider receive-chain or coil problem if repeatable across protocols

Shading / Uneven Signal

One region is noticeably brighter or darker than expected.

First: Applications / Tech checks

  • Check patient centering and coil selection
  • Check whether intensity correction or protocol settings changed
  • Repeat with a known-good protocol if appropriate

Then: Engineer checks

  • Inspect coil element/channel behavior
  • Consider B1/calibration issues
  • Compare another coil if available and appropriate

Zipper / RF Interference

Narrow line or repeating RF-related artifact through the image.

First: Applications / Tech checks

  • Check whether artifact occurs on multiple sequences
  • Determine whether it follows one coil or all coils
  • Check for permitted removable interference sources

Then: Engineer checks

  • Review RF shielding/door condition and obvious interference sources
  • Check coil/cable integrity
  • Use OEM RF procedures before invasive service

Ghosting / Repeated Anatomy

Copies or ghosts of anatomy appear along an encoding direction.

First: Applications / Tech checks

  • Check motion/respiration and phase direction
  • Review timing/gating if used
  • Compare with a known-good protocol

Then: Engineer checks

  • If persistent on phantom/known-good protocols, review gradient/reconstruction path
  • Review system logs and gradient-related artifacts

Geometric Distortion

Anatomy or phantom geometry is warped, stretched or displaced.

First: Applications / Tech checks

  • Check sequence type and bandwidth
  • Check positioning and prescribed FOV
  • Determine whether distortion is localized or global

Then: Engineer checks

  • Review gradient performance if present on known-good phantom scans
  • Consider B0/shim effects where applicable
  • Follow OEM geometry/gradient checks

Signal Dropout

Unexpected localized or broad loss of signal.

First: Applications / Tech checks

  • Check coil coverage/element selection
  • Check susceptibility-prone sequence/location
  • Review positioning and protocol changes

Then: Engineer checks

  • Check coil connector/cable and element behavior
  • Compare another known-good coil if appropriate
  • Review receive chain if reproducible

Wrap / Aliasing

Anatomy outside the FOV folds into the displayed image.

First: Applications / Tech checks

  • Check FOV and phase direction
  • Check no-phase-wrap/oversampling settings
  • Verify anatomy is adequately covered

Then: Engineer checks

  • Usually protocol/coverage related before hardware
  • Escalate if abnormal on known-good protocols

Poor Fat Suppression

Fat remains bright or suppression is spatially uneven.

First: Applications / Tech checks

  • Confirm fat-sat/STIR method and protocol
  • Check patient centering and anatomy location
  • Review shim/prescan and sequence choice

Then: Engineer checks

  • Consider B0 homogeneity/shim or center-frequency issues
  • Compare with known-good protocol/phantom where appropriate
